# Neon Tempo

An 80s-meets-90s drum rhythm game, made with Manaki, Mati & Kian. (Working title.)

**Play it:** https://crisai2026.github.io/neon-tempo/ (once GitHub Pages is turned on)

Notes slide toward a ring. Hit them in time with **D** (kick), **F** (snare), **J** (hi-hat) and **K** (crash), or tap the on-screen pads.

- Two levels: Beginner and Medium
- Four original tracks, composed in code: Cassette Highway, Mall Laser Pop, Dial-Up Jazz Café, Zombie Videoclub
- Perfect / Good / Miss, combos and a x4 multiplier

Open `index.html` in a browser to play. Adjustable values live in the `CONFIG` block at the top of the script.
